NATIVE HTML, SAME API

简单属性，熟悉的选项

<button data-eui="button" data-variant="tonal" data-size="md">保存</button>

<span><input data-eui="text-field" data-label="你的名字"></span>

<div data-eui="progress" data-label="上传进度"
     data-eui-options='{"value":0.6,"wavy":true}'></div>

data-variant、data-size、data-label 等常用属性可直接写。更多选项放入 data-eui-options JSON，名称与 npm API 一致。输入控件保留专用的 <span> 包装，文字放在包装之外。

自动初始化支持动态插入的元素，移除元素时会释放控制器。普通 HTML 事件和表单行为照常使用。每个元素只采用一种初始化方式。

在 API Studio 切换到「CDN HTML」，复制每个组件的完整示例 →

需要更多控制时，直接调用 JS

<button id="save">保存</button>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const button = ExpressiveUI.enhanceButton(document.querySelector('#save'), {
      variant: 'filled', size: 'md'
    });
    // 卸载时调用 button.destroy()
  });
</script>

所有原生组件均可通过 ExpressiveUI.enhance…() 使用。引擎分别位于 ExpressiveUI.core、.shape、.motion、.tokens、.theme。对声明式组件，可用 ExpressiveUI.getController(element) 取得控制器。

直接引用的文件

expressive-ui.js 普通 script · 全部原生 API + 自动初始化expressive-ui.css 全部样式 · 内置主题与字体expressive-ui.module.js ES Module · 相同导出import-map.json 七个包与 React 的浏览器模块映射

也可从 /cdn/components.js、/cdn/core.js 等模块按包导入，函数名、参数和返回控制器与 npm 一致。React 适配器位于 /cdn/adapter-react.js；使用 import map 中配套的 React 模块，TSX 仍需转译。

这些地址随本站部署更新。JS、CSS、字体和按需加载的形状数据均托管在本站 Vercel，支持跨域引用。生产项目需固定内容时，可下载文件及其依赖自行托管。
